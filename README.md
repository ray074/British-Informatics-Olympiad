# British-Informatics-Olympiad

## Overview

This repo holds my solutions to questions presented in the [British Informatics Olympiad](https://www.olympiad.org.uk/), the national computing competition for schools and colleges. 

## Key concepts and techniques demonstrated

Across these British Informatics Olympiad solutions, I have developed and applied a strong foundation in algorithmic problem solving: translating informal mathematical puzzles into precise computational models, decomposing them into manageable subproblems, and implementing clear, logically structured solutions.

- **Algorithmic thinking and mathematical modelling**  
  Converting Olympiad-style problem statements into rigorous computational logic, identifying the underlying mathematical structure, and designing solution strategies that are both correct and elegant.

- **Discrete mathematics, number theory, and combinatorial reasoning**  
  Applying ideas such as primes, factorisation, divisibility, integer representations, recurrence-based structures, and constrained counting to solve the more mathematical problems.

- **String algorithms, symbolic manipulation, and rule-based processing**  
  Implementing transformations over strings, encodings, custom representations, and pattern-driven logic, with careful attention to edge cases and exact specification.

- **Simulation, constructive methods, and iterative algorithm design**  
  Modelling evolving systems over sequences, grids, and finite states, while also using greedy, constructive, and recurrence-driven approaches to build valid solutions efficiently.

- **Python implementation, data structures, and correctness-focused problem solving**  
  Using Python to produce concise and reliable solutions, selecting appropriate core data structures such as lists, sets, dictionaries, and 2D arrays, and maintaining a strong focus on correctness, robustness, and implementation discipline.
