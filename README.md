# British-Informatics-Olympiad

## Overview

This repo holds my solutions to questions presented in the [British Informatics Olympiad](https://www.olympiad.org.uk/), the national computing competition for schools and colleges. I've practiced translating mathematical questions into computational models, with a focus on identifying the key data structures and algorithms of the problem to create optimised solutions. My solutions have been implemented in Python and use only standard libraries in appropriate places. I've place strong emphasis on the testing process, ensuring that any edge-cases return correct, reliable results. All solutions score full marks when tested.
